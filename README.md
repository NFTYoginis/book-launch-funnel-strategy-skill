# Book Launch & Funnel Strategy

A folder-based ICM specialist that designs the growth architecture around a just-finished or just-published book — and, most distinctively, makes the judgment call of whether a book's companion site should be a sales funnel or a publishing platform, by asking one question first instead of assuming.

This formalizes a real launch (channel sequencing, a locked-token launch pattern, a 6-email sequence) and a real, documented mistake and its own correction: a full funnel/ecosystem was built for a book, recognized as miscast, and replaced with a four-verb filter. It is not a theory of launch strategy — it's a repeat of what already worked, and a repeat of a mistake already caught and fixed.

## What this is

Six disciplines, applied to a book's launch:

1. **The funnel-vs-companion-site judgment call** — the skill's whole reason for existing. Ask first whether a real paid program exists behind the book; the answer picks the model.
2. **The four-verb filter** — does this help the reader ENTER, UNDERSTAND, CONTINUE, or DEEPEN the book? Every companion-site page runs through it.
3. **Owned → borrowed → earned channel sequencing** — prove assets convert before spending goodwill on cold pitches.
4. **The locked-token launch pattern** — build everything copy-ready except one blocked external dependency, swap it once, verify with a zero-remaining check.
5. **The 6-email launch sequence** — value-first, CTA-second, the book's own protected lines threaded through.
6. **Honest comparables analysis** — separate what's directly sourced from what's a digest reconstruction.

Full detail per discipline: `reference/`.

## Setup

1. Load this folder into a Claude Project, or point a Claude Code session at it — `SKILL.md` lets Claude Code auto-discover and trigger it from a natural request (e.g. "plan this book's launch" or "is this a funnel or a companion site"); it routes to `identity.md` → `rules.md`, then to the one `reference/` file the active situation needs.
2. Working from the raw files directly (no `SKILL.md` support): read `identity.md` → `rules.md` → `examples.md` in that order, then open only the `reference/` file for the discipline actually in play.
3. Before anything else, answer one question: does a real paid program or ladder exist behind this book? Don't guess — this determines which model the rest of the launch follows.

## First-run prompts

- *"Plan this book's launch."*
- *"Does this book need a funnel, or is it a companion site?"*
- *"Build the email launch sequence."*
- *"Sequence the outreach — who do we pitch first?"*

## What this specialist does and doesn't do

See `identity.md` and `rules.md` for the full contract. In short: it never writes final marketing copy, never builds the site, never spends ad money, never repurposes the book's own content, and never lets pricing tiers onto a page that's supposed to be trust-building — it owns the launch architecture and the judgment call underneath it, using a discipline built from a real launch and a real corrected mistake.
