The four-verb filter

Every page on a companion site has to earn its place. If it doesn't map to one of these four verbs, it doesn't belong — no matter how much work went into it.

Enter

The question, as the on-ramp. The most inviting version of what the book asks.

Understand

The answer, and the proof. Why the book is worth the reader's time.

Continue

The book's own material, extended — what a chapter flagged, followed through.

Deepen

Going further, for the reader who wants more — still in service of the book.

The refusal gate this skill runs on

"I won't let pricing tiers or an offer architecture onto a page that's supposed to be trust-building — the moment pricing psychology appears, the genre breaks. Whether a real paid program exists behind this book is the first question, asked explicitly, never inferred by adding tiers later."

Owned → borrowed → earned

Prove the assets convert before spending goodwill on a cold pitch.

1 · Owned

The author's own list, podcast, socials. Do these first — this week.

2 · Borrowed

Warm network, cross-promotion to adjacent audiences. Low-friction, existing trust.

3 · Earned

Cold pitches, tiered by fit, one customized asset per outlet. Never a blast pitch.

The 6-email launch sequence

Value first, CTA second — the ask doesn't appear until email 6, earned by five emails of real content.

  • 1WelcomeThe core question, stated plainly. No softening-up for a pitch.

Launches architected on this discipline

Setup

  1. Load this folder into a Claude Project, or point a Claude Code session at it — SKILL.md lets it auto-discover and trigger from a natural request.
  2. Answer one question first: does a real paid program or ladder exist behind this book?
  3. Run every proposed companion-site page through the four-verb filter before building it.
  4. Sequence outreach owned → borrowed → earned; never a blast pitch on the earned tier.
  5. Hand the strategy to content-claude for copy and to Builder for the site — this skill specifies, it doesn't write or build.

FAQ

Does it write the actual sales page copy?

No — it specifies what the page has to accomplish. content-claude executes the final prose in brand voice.

What if the book genuinely has a paid program behind it?

Then it gets the funnel model, built honestly as a funnel — this skill doesn't refuse funnels, it refuses funnel logic imported onto a site that doesn't actually have one.

Does it build the companion site itself?

No — that's the Builder worker's job. This skill hands over the architecture and the four-verb-filtered page list.

What if the live comparables scan fails?

It says so — same disclosure discipline as Fact-Verification's UNVERIFIED banner. No silent guessing.
